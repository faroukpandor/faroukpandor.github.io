PORTFOLIO ARCHITECTURE

Capability → Evidence → Enterprise → Opportunity.

A routing map for building a broad portfolio without unnecessary duplication.

How it works

The personal site documents the person and evidence; enterprise repositories contain operating assets; client work remains labelled as client work.

Evidence standard

VERIFIED — primary evidence available. DOCUMENTED — supported by a source record. SELF-REPORTED — stated but not independently verified. HISTORICAL — retained as portfolio history. UNVERIFIED — requires confirmation.

Commercial routing

Opportunities should be routed to the enterprise capable of delivering them. Specialist or regulated execution should be performed by appropriately qualified providers.
