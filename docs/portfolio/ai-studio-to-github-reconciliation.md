# AI Studio → GitHub Reconciliation

The Google AI Studio inventory belongs to **faroukpandor@gmail.com**.

## Reconciliation method
For each AI Studio app:
1. Search GitHub by exact name and variants.
2. Inspect README, package metadata and links.
3. Search deployment/domain references.
4. Compare architecture and features.
5. Check commit history where available.
6. Determine whether the GitHub repository is a prototype, canonical implementation, client implementation, fork, duplicate or unrelated project.
7. Record confidence and unresolved questions.

## Provenance
An AI Studio app may have subsequently been worked on by other AI agents. This is development history, not automatic ownership transfer.

## Do not
- assume matching names mean matching projects;
- overwrite production repositories from prototypes;
- delete an AI Studio app because a GitHub repository exists;
- treat generated code as proof of ownership.

## Desired output
Every matched pair should eventually have:
**AI Studio App ↔ GitHub Repo ↔ Deployment ↔ Enterprise/Product ↔ Ownership ↔ Status**.
