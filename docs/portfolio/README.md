# Farouk Pandor — Portfolio Control Plane

This directory is the portfolio-control layer for the Farouk Pandor ecosystem.

It records relationships between GitHub repositories, Google AI Studio applications, Google Drive/Docs assets, deployments, domains, enterprises, clients, experiments and work potentially developed with other AI agents.

## Account provenance

The Google AI Studio inventory recorded in this portfolio is associated with **faroukpandor@gmail.com**.

## Operating principle

Every digital asset should have:
1. owner/provenance classification;
2. canonical repository or storage location;
3. enterprise/product relationship;
4. lifecycle status;
5. backup/recovery path;
6. source-of-truth designation.

Do not duplicate production code merely to create a portfolio record.

## Lifecycle

DISCOVERED · TRIAGED · ACTIVE · CANONICAL · CLIENT · INCUBATING · MERGE-CANDIDATE · ARCHIVE · RETIRED · UNKNOWN

## Control rule

No repository, AI Studio app or document is assumed to be disposable merely because it is old, small, untitled or duplicated. Inspect first for reusable code, business logic, research, prompts, designs, data, configuration references and intellectual property.
