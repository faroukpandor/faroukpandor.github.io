# Asset Lifecycle

## States
DISCOVERED → TRIAGED → VALIDATED → ACTIVE → CANONICAL → MONETISING → MAINTENANCE → INCUBATING → MERGE-CANDIDATE → ARCHIVE → RETIRED

## Rules
- DISCOVERED: existence known; little verified.
- TRIAGED: basic purpose/provenance recorded.
- VALIDATED: evidence and ownership understood.
- ACTIVE: deliberate development.
- CANONICAL: designated source of truth.
- MONETISING: revenue pathway operating or being tested.
- MAINTENANCE: useful but not actively expanding.
- INCUBATING: promising but not validated.
- MERGE-CANDIDATE: overlapping assets require comparison.
- ARCHIVE: preserved, no active development.
- RETIRED: deliberately discontinued with evidence retained.

No destructive lifecycle transition without documentation.
