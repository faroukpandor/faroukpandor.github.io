# Africa Intelligence and Commercial Resilience

## Principle
No single repository, API, AI provider, website, automation workflow or data source may be a single point of failure.

## Source fallback
PRIMARY OFFICIAL SOURCE
→ alternate official source
→ credible archival/reference source
→ manual research queue.

## Data fallback
PWA/database
→ CSV/JSON export
→ spreadsheet
→ manual paper/WhatsApp record
→ later reconciliation.

## Service fallback
Automated workflow
→ manual checklist
→ direct supplier/customer communication
→ transaction record
→ reconcile when systems recover.

## AI fallback
Preferred AI
→ alternate free AI
→ deterministic rules/templates
→ human review.

## Hosting fallback
Primary static host
→ GitHub Pages
→ another portable static host where needed.

The goal is graceful degradation, not technological perfection.
