# Botswana Opportunity Discovery and Routing SOP

**Status:** Operational research SOP — 2 October 2026  
**Purpose:** Turn Botswana development priorities and persistent national problems into evidence-based commercial experiments.

## 1. Trigger

Use this SOP when:
- a national/district development priority is identified;
- a customer problem appears to correspond to a persistent development bottleneck;
- a supplier/product opportunity is discovered;
- an import-substitution/value-add/export opportunity appears;
- a Facebook/WhatsApp/web lead reveals a repeatable need;
- research identifies a potential commercial gap.

## 2. Workflow

**Signal → Verify → Localise → Define problem → Identify customer → Map value chain → Identify capability → Test economics → Select experiment → Execute → Measure → Decide → Route/scale/archive**

### Gate 1 — Verify the signal
Record:
- source;
- publication date;
- official/secondary status;
- exact claim;
- relevant plan/programme;
- source URL;
- retrieval date.

### Gate 2 — Localise
Record:
- district;
- town/village;
- production base;
- existing providers;
- infrastructure/logistics constraints;
- local market;
- potential regional market.

NPC states that district planning precedes national planning, making spatial context material to opportunity research. 

### Gate 3 — Define the customer problem
Do not start with “Government wants X.”

Start with:
- Who has the problem?
- What does it cost them?
- How do they solve it now?
- How often does it occur?
- Who pays?
- What evidence shows urgency?

### Gate 4 — Map the value chain

**Input → Production → Processing → Packaging → Logistics → Distribution → Customer → After-sales**

Mark:
- imported inputs;
- Botswana suppliers;
- missing capability;
- bottleneck;
- potential local value addition;
- quality/compliance requirement;
- export opportunity.

### Gate 5 — Route to the correct Farouk-owned asset

Use the smallest appropriate owner:

| Opportunity | Primary route |
|---|---|
| General product/request | General Dealer architecture |
| Sourcing/import/resale | General Dealer / BW Imports where appropriate |
| Agricultural operations | AgriSage360 / AgriSolutions |
| Digital productivity | Mokoro / digital operations |
| Vehicle sourcing | AutoLink |
| Discovery/market intelligence | EverythingCity / Research |
| Branding/custom merchandise | Brandcraft / production coordination |
| Specialist trades | Provider/Referral Network |
| Indigenous bioresources | Indigenous Bioresource Research |
| Business administration | Business Operations Desk |

If the opportunity belongs to a client/employer/third party, route it there and do not represent it as Farouk-owned.

### Gate 6 — Economics

Calculate:

**Direct/Landed Cost = supplier cost + freight + insurance where applicable + duties/taxes/levies + clearing/handling + local transport + transaction/payment costs + documented risk allowance**

**Gross Contribution = selling price − direct/landed cost**

Then separately account for overhead, tax and owner compensation.

### Gate 7 — Compliance

Check:
- licensing;
- product restrictions;
- import requirements;
- professional qualifications;
- food/health requirements;
- vehicle requirements;
- environmental requirements;
- data/privacy;
- consumer obligations;
- tax/accounting requirements.

Unresolved compliance = HOLD, not “proceed and fix later.”

### Gate 8 — Select the smallest commercial experiment

Examples:
- one paying customer;
- one supplier comparison;
- one imported item versus local alternative;
- one farm workflow;
- one custom merchandise order;
- one delivery route;
- one provider referral;
- one regional buyer conversation.

### Gate 9 — Measure

Minimum:
- enquiry;
- qualified opportunity;
- quote;
- customer commitment;
- completed transaction;
- contribution;
- fulfilment time;
- failure/rework;
- repeat purchase;
- referral;
- local providers/suppliers used;
- value added locally.

### Gate 10 — Decision

Use:
- **SCALE** — repeatable evidence.
- **ITERATE** — demand exists but economics/process need improvement.
- **HOLD** — evidence insufficient.
- **ROUTE** — belongs to another owned enterprise.
- **PARTNER** — requires specialist/provider.
- **ARCHIVE** — no evidence or unacceptable economics/risk.

## 3. Resilience rule

No opportunity should depend on one:
- supplier;
- platform;
- social-media page;
- payment channel;
- hosting provider;
- individual contractor;
- data store.

Where commercially material, identify:
- primary;
- alternate;
- fallback/manual process.

## 4. Anti-policy-chasing control

A policy match is never sufficient.

**Policy relevance + customer problem + evidence + capability + viable economics + acceptable risk = candidate opportunity.**

If any material component is missing, the opportunity remains research rather than a commercial commitment.
