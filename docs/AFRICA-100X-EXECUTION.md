# Africa Opportunity Engine — 100x Execution

This register coordinates one hundred evidence-producing passes across country, regional, supplier, customer, economics, compliance, delivery and resilience research.

Rule: each pass must add evidence, improve an operational asset, validate a customer/supplier assumption, record a transaction, or make a documented decision. Repetition without new evidence does not count.

Completion states: READY, RESEARCHING, VERIFIED, CUSTOMER-VALIDATED, SUPPLIER-VALIDATED, PAID-PILOT, REPEATABLE, ROUTED, HOLD, ARCHIVED.

No unverified claim becomes fact. Farouk-owned, client, employer and third-party assets remain explicitly separated. Every material source receives provenance and retrieval date. Every automated process has a manual fallback.
