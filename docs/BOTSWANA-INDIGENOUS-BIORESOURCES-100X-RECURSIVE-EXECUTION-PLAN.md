# Indigenous Bioresources 100x Recursive Execution Plan

**Research date:** 2 October 2026  
**Purpose:** Execute the next 100 research/commercialisation passes as controlled evidence cycles rather than duplicating documents.

## Operating rule

Each recursion must advance at least one of:

**Evidence → Actor → Requirement → Specification → Supplier → Economics → Compliance → Customer → Transaction → Outcome → Repeatability**

A pass that adds no new evidence, decision, actor, requirement or executable next action is not counted as productive recursion.

## Evidence hierarchy

**Primary official / institutional → peer-reviewed → verified commercial record → supplier documentation → observed transaction → self-report → unverified lead.**

No lower-grade source upgrades itself merely by repetition.

## Commercial gate

No inventory, biological collection, regulated claim, institutional representation, technology licensing assumption or major expenditure follows from research alone.

Required progression:

**SIGNAL → VERIFIED REQUIREMENT → QUALIFIED ACTOR → SPECIFICATION → ECONOMICS → COMPLIANCE → CUSTOMER COMMITMENT → PAID PILOT → DELIVERED OUTCOME → REPEAT.**

## Resilience

Every important opportunity must remain reconstructable from portable records:

**Opportunity ID + actor + requirement + evidence + supplier + economics + compliance + status + next action.**

If an application, repository, API or website fails, the work continues from CSV/JSON/spreadsheet/manual records.

## Current priority after Pass 010

The next productive recursion should begin with **current actor and service-price verification**, using NARDI, BITRI, BOBS/BoMRA and current commercial actors, before expanding into more species.

The 100-pass programme is therefore a controlled research backlog, not a commitment to manufacture 100 documents or create 100 businesses.
