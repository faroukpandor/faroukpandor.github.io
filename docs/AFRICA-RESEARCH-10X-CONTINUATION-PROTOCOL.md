## Current recursive rule

Do **not** create more generic country reports merely to increase document count.

The next pass must move one or more signals downstream into:
1. a named customer/project;
2. an exact requirement;
3. a verified supplier/provider;
4. product/service specifications;
5. price and lead-time evidence;
6. landed economics;
7. compliance/eligibility;
8. customer commitment or paid pilot/transaction;
9. delivery outcome;
10. repeatability evidence.

If a signal cannot pass a gate, record the reason and move it to HOLD, DECLINED or ARCHIVE.

## Resilience rule

Every evidence workflow must have:
**primary source → alternate official source → archived/reference copy → manual research queue.**

Every commercial workflow must have:
**digital record → portable CSV/JSON/spreadsheet → manual/WhatsApp execution → later reconciliation.**

Every automated decision must preserve:
**source provenance → retrieval date → evidence class → human review where material.**

Every ownership-sensitive record must state:
**Farouk-owned / client-owned / employer-owned / third-party / unknown.**

No policy alignment, investment-promotion statement, procurement plan, tender notice, website traffic, social following, AI estimate or repository activity is sufficient by itself to declare market proof.
