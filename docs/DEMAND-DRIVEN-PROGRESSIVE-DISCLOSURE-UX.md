# Demand-Driven Progressive Disclosure UX

**Status:** Canonical portfolio UX principle

## Principle

**User demand determines what the interface reveals.**

The visitor should not have to understand Farouk's enterprise architecture, commercial modes or internal workflow to request help.

## Public journey

**Need → Clarify → Route → Act → Outcome**

The interface should reveal only the next useful decision.

## Napkin-inspired visual communication

Use the communication principles associated with visual storytelling tools such as Napkin:

- concise text;
- one idea per visual;
- flows for processes;
- cards for choices;
- relationships before decoration;
- progressive disclosure;
- visuals as explanations rather than ornament.

This is inspiration at the communication-method level only. Do not copy proprietary UI, branding, assets or layouts.

## Demand entry categories

Initial categories may include:

- product/sourcing;
- service/specialist;
- business support;
- agriculture;
- research/information;
- opportunity/partnership;
- other.

These are customer language, not mandatory enterprise categories.

## Routing rule

A visitor selection is an input, not a final diagnosis. The system may ask clarifying questions before selecting a capability or enterprise.

## Complexity boundary

Public:
- need;
- useful questions;
- clear next step;
- relevant explanation.

Internal:
- opportunity IDs;
- evidence;
- supplier/provider verification;
- economics;
- compliance;
- working capital;
- fulfilment;
- outcome;
- learning.

## UX acceptance tests

A first-time visitor should be able to:

1. identify a relevant starting point without knowing enterprise names;
2. begin an enquiry without completing a long form;
3. understand the next step;
4. avoid seeing irrelevant portfolio complexity.

## Reuse

Apply this pattern to enterprise websites and applications where appropriate. The same demand language may route to different specialist systems behind the scenes.

**Design rule: broad capability behind the interface; focused experience in front.**
