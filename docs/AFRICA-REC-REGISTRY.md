# African Regional Economic Community Registry

Track regional institutions as commercial-context layers, not as substitutes for country law.

## Initial REC set
- SADC
- COMESA
- EAC
- ECOWAS
- ECCAS
- IGAD
- CEN-SAD
- AMU

## Required fields
`rec_id`, `name`, `member_states`, `treaty/framework`, `trade_instruments`, `industrial_priorities`, `infrastructure_priorities`, `services/trade rules`, `customs/trade facilitation instruments`, `official_sources`, `last_verified`.

## Commercial control
REC-level policy is a signal. Before quoting or transacting, verify the specific country, product/service, origin, destination, customs treatment, standards and applicable permissions.
