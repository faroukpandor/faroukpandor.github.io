## Acquisition-to-outcome chain

**Channel → enquiry → qualified opportunity → matched offer/provider → quote/referral → fulfilment → completed outcome → contribution → repeat/referral**

## Audit rule

Do not create a replacement page or new channel merely because an existing page is informal.

First determine:

1. what audience it reaches;
2. what enquiries it generates;
3. what services/products those enquiries concern;
4. whether the page is controlled;
5. whether enquiries can be captured centrally;
6. whether it has produced completed transactions;
7. whether it should be retained, repositioned, consolidated or retired.

## Governance

Existing pages are not automatically separate enterprises.

They are acquisition assets unless there is evidence and an explicit decision that a page represents a distinct enterprise, brand or client relationship.

Never publish private customer/provider records to GitHub.
