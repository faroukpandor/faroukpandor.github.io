# Botswana Indigenous Bioresources — Commercial Economics Passes 061–070

**Research date:** 2 October 2026  
**Status:** economic-control framework; figures must be populated from current quotations, transactions or verified institutional pricing.

## Pass 061 — Current price collection

Historical prices are evidence of past transactions or observations, not current quotations.

For every input/output record:
**item → specification → supplier/buyer → location → currency → price basis → quantity/MOQ → validity date → source → verification date.**

NARDI currently publishes a 2026 pricing document for its products/services, giving a primary institutional reference point where a relevant service is actually offered. citeturn0search0

## Pass 062 — Supplier quotations

A supplier listing is not a quotation.

A usable quote should capture:
- exact specification
- quantity/MOQ
- unit price
- currency
- Incoterm/delivery basis where relevant
- validity
- lead time
- payment terms
- warranty
- exclusions
- tax/duty treatment
- supplier identity and verification evidence.

For Farouk's sourcing model, this becomes the supplier-evidence layer before customer quotation.

## Pass 063 — Equipment landed cost

Imported equipment must be modelled beyond supplier price:

**equipment price + freight + insurance + customs duty + VAT + clearing/handling + local transport + installation + commissioning + testing + contingency = landed/installed cost.**

BURS states that imports from outside SACU are subject to 12% VAT plus applicable tariff rates, while SACU imports generally attract 12% VAT under its published assessment guidance. Exact treatment remains product-specific. citeturn0search3turn0search4

Therefore “FOB/CIF/shipping included” must never automatically be described as Botswana landed cost.

## Pass 064 — Packaging cost

Packaging economics must be product-specific:

**container + closure + liner/barrier + label + printing + coding + secondary packaging + wastage + packing labour + transport/storage.**

For food, packaging selection also has to match the product's moisture, oxygen, light, contamination and shelf-life requirements.

## Pass 065 — Processing cost

Processing cost should be measured per batch:

**raw material + labour + electricity/fuel + water + equipment use + maintenance + cleaning + wastage + quality/testing + packaging + internal movement.**

Separate fixed and variable costs.

Do not use machine purchase price as the entire processing cost; calculate an appropriate use/depreciation or lease cost.

## Pass 066 — Laboratory/testing cost

Testing must be tied to a specification and regulatory/customer requirement.

NARDI's Food Science and Technology programme describes food safety/quality methods covering contaminants, adulterants, pesticides, mycotoxins, heavy metals, toxins and other concerns, and states that it develops methods required by customers/markets. citeturn0search2

The cost model therefore needs:
**test → sample requirement → laboratory → price → turnaround → repeat-test probability → interpretation/corrective action.**

Use current institutional price schedules where applicable rather than assumed laboratory fees.

## Pass 067 — Logistics

Logistics must distinguish:
**supplier → collection → consolidation → freight → border/customs → clearing → destination → customer.**

For biological/food products, add relevant storage and handling constraints.

Record actual and quoted logistics separately so the system can learn the difference between estimates and realised costs.

## Pass 068 — Working capital

A profitable transaction can still create a cash-flow failure.

Record:
- customer deposit
- supplier deposit
- remaining supplier balance
- freight/payment dates
- taxes/duties
- testing
- production
- customer balance
- expected collection date
- cash gap
- maximum exposure.

**Rule:** no order should be accepted without identifying who funds each stage and when.

## Pass 069 — Contribution margin

For each product/service:

**Revenue − variable/transaction-specific cost = contribution.**

Contribution should include all directly attributable costs, including sourcing/coordination, payment costs, logistics, testing and expected wastage where applicable.

Do not confuse markup with margin.

## Pass 070 — Break-even

For a stable contribution model:

**Break-even units = fixed costs ÷ contribution per unit.**

For mixed services/projects, use contribution per project or contribution per customer cohort instead.

Run sensitivity cases for:
- input-price increase
- FX movement
- yield loss
- freight increase
- delayed payment
- failed batch
- additional testing
- supplier delay
- customer cancellation.

## Indigenous-bioresource economic model

The minimum opportunity record should now connect:

**Opportunity ID → resource → specification → supplier/producer → quantity → input price → processing → testing → packaging → logistics → working capital → customer price → contribution → break-even → compliance → evidence → status.**

## Commercial gate

**CURRENT PRICE → VERIFIED QUOTE → COMPLETE COST → CUSTOMER PRICE → CONTRIBUTION → CASH-FLOW CHECK → CUSTOMER COMMITMENT → TRANSACTION → REALISED COST → REALISED OUTCOME → REPEAT.**

A research paper, institutional programme, supplier catalogue or historical WTP study cannot substitute for this sequence.
