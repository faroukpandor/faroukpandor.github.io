# Portfolio Evidence Map

## Purpose
The personal repository is the human/professional layer. It connects capabilities and evidence to canonical enterprise repositories without duplicating them.

## Routing principles
1. One capability should have one canonical enterprise destination where practical.
2. Personal claims require evidence classification.
3. Client/employer work is not ownership.
4. Historical concepts remain historical unless reactivated and verified.
5. Regulated work must be routed to appropriately qualified professionals.
6. A repository is not automatically an enterprise; ownership and status must be confirmed.

## Portfolio lifecycle
IDEA → RESEARCH → EXPERIMENT → PROJECT → DEVELOPING → ACTIVE → COMMERCIAL → ARCHIVED

Status should never be inferred merely because a repository exists.

## Evidence ledger fields

- canonical enterprise
- repository
- ownership status
- lifecycle status
- evidence class
- source/evidence location
- date verified
