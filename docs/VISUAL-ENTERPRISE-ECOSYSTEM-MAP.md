# Visual Enterprise Ecosystem Map

The personal portfolio is a routing layer rather than a monolithic enterprise.

## Core model

**Farouk Pandor = human + commercial orchestration layer**

Visitors should understand:

**Problem → Requirement → Evidence → Capability → Destination → Delivery → Outcome → Learning**

## Visual destinations

- Commercial: sourcing, reselling, procurement, referral and market entry
- Research: evidence, intelligence, validation and opportunity discovery
- Digital: systems, automation, data and implementation
- Agriculture: farm operations, AgTech and animal systems
- Discovery: comparison, events and commercial information

## Design control

The visual map explains relationships; it does not establish ownership, market validation, regulatory status or customer commitment.

Ownership and evidence classifications remain authoritative in the repository documentation.

## Future evolution

The map can progressively become an interactive SVG/HTML information architecture with links to:
- enterprise repositories
- evidence records
- commercial offers
- opportunity experiments
- customer routes
- ownership classifications
- resilience/fallback documentation.

Core functionality remains static and portable.
