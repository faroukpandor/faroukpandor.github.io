# Africa Opportunity Ledger Schema

Portable across CSV, JSON, spreadsheet, PWA and MOKORO.

## Core record
`opportunity_id`
`country`
`REC`
`city_or_region`
`sector`
`problem`
`customer_segment`
`customer`
`source_signal`
`evidence_ids`
`supplier/provider`
`commercial_mode`
`currency`
`supplier_cost`
`logistics_cost`
`duties_taxes_fees`
`coordination_cost`
`target_price`
`expected_contribution`
`compliance_status`
`status`
`responsible_asset`
`next_action`
`review_due`

## Status
NEW → QUALIFYING → SOURCING → QUOTED → CUSTOMER-COMMITTED → PROCUREMENT → IN-FULFILMENT → DELIVERED → RECONCILIATION → CLOSED.

Alternative exits: DECLINED / LOST / ON-HOLD / CANCELLED.

## Ownership
Only Farouk-owned assets may be routed as owned assets. Client/employer/third-party assets must be explicitly labelled.
