# Personal documents

These are Farouk Pandor's personal records: CVs, degree certificate, the Tirelo Sechaba letter and a personal profile.

## Read this first — these files are public

This repository is **public** and GitHub Pages publishes from the `/` of the `main` branch. Anything committed here is downloadable by anyone who has the URL, whether or not a page links to it. `robots.txt` now disallows this folder, but that only discourages search engines; it does not restrict access.

The folder exists so the repository root stays clean and the site's own files are easy to tell apart from personal records. It is **not** a security boundary.

If you want these genuinely private, one of these is required:

1. **Make the repository private** — Settings → General → Danger Zone → Change visibility. This stops Pages publishing the user site until you either make the repo public again or move the site to a private-repo-compatible host.
2. **Remove the files and purge history** — `git filter-repo` or BFG, then force-push. Deleting them in a new commit is not enough; they stay reachable in history.
3. **Keep personal records outside the repository entirely** — Google Drive or Dropbox, shared by individual link. This is the recommended option.
