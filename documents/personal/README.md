# Documents

Reference material that supports the content on this site.

## `personal/`

This folder used to hold scans of personal documents — a degree certificate, a
national service certificate, CVs, an application letter and a personal profile
containing identity and banking details.

**Those files have been removed from this repository.** This repository is public
and publishes directly to GitHub Pages, so anything committed here is served to
anyone who requests the URL. Personal identity documents, certificates and
financial details do not belong in a published site, whatever the folder is
called and whatever `robots.txt` says.

What remains is a single item of public reference material:

- `beekeeping-circular-3-of-2026-page-1.jpeg`
- `beekeeping-circular-3-of-2026-page-2.jpeg`

These are photographs of **External Advertisement — Vacancy Circular No. 3 of
2026**, issued by the District Agricultural Coordinator, Goodhope, on 21 October
2026. They are a government public notice and contain nothing confidential.

## Note on history

Removing a file from the current commit does not remove it from earlier commits.
The personal documents above still exist in this repository's history and can be
retrieved by anyone who clones it and looks. Squaring that away properly requires
rewriting history or making the repository private — both are decisions for the
repository owner, not something to be done silently.

## Adding files here

Do not commit personal documents to this folder. `.gitignore` now blocks the
common document and image types in `documents/personal/` as a guard, but the
guard is a convenience, not a substitute for keeping such files off a public
remote in the first place.
